# CV Maker Pro - Flutter Mobile App

Flutter Android app for CV Maker Pro. Talks to the Django backend (`../backend`)
through REST APIs under `/api/v1/`.

## Platform files

The android platform files are generated by Flutter. After cloning run once:

```bash
flutter create . --org com.cvmakerpro --project-name cv_maker_pro
```

Then merge the AdMob `APPLICATION_ID` meta-data (from `android/app/src/main/AndroidManifest.xml` in this repo) into the generated manifest.

## Setup

```bash
cd mobile
flutter pub get
flutter doctor
```

## Run against the local Django server

Android emulator (backend on the same PC):

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1
```

Real phone on the same network:

```bash
flutter run --dart-define=API_BASE_URL=http://<YOUR_PC_LAN_IP>:8000/api/v1
```

Ensure Django `ALLOWED_HOSTS` includes the LAN IP.

## AdMob

Test ad unit IDs are used by default. For production pass:

```bash
flutter run --dart-define=ADMOB_APP_ID=ca-app-pub-XXXX~YYYY \
  --dart-define=ADMOB_REWARDED_UNIT_ID=ca-app-pub-XXXX/YYYY
```

The rewarded flow uses AdMob Server-Side Verification (SSV); Google calls the
backend `/api/v1/ads/ssv/` endpoint with a signed payload that Django verifies
using Google's Ed25519 public key. The Flutter client never verifies anything
itself and cannot forge credits.

## Features

- Guest login + upgrade preserving all CVs
- Template gallery with live JSON schema v1.0 previews
- CV info form with repeatable sections
- Canva-like editor: select, drag, resize, rotate, layers, undo/redo, zoom, multi-page
- My CVs, duplicate, versions
- PDF export with rewarded-unlock fallback
- AI tools with credit + rewarded session flow
- ATS checker + JD matcher
