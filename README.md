# CV Maker Pro

Canva-like CV Maker platform: **Flutter Android app + Django backend (REST API + Tailwind Admin Panel) + MySQL**.

- **PRD:** [docs/PRD.md](docs/PRD.md) (v2.0 — Django stack)
- **Backend:** `backend/` — Python Django + Django REST Framework
- **Mobile:** `mobile/` — Flutter (Android)
- **Docs:** API, database and deployment guides in `docs/`

Free forever — monetized through AdMob rewarded ads only (AI credits + PDF export credits). No payments, no subscriptions, no premium templates, no watermark.
